## 🏗️ Installation & Running Locally
Clone the repository:
```bash
git clone https://github.com/pjorgesilvaa/portfolio.git
cd portfolio
```

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```
